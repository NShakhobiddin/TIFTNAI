# Dekla AI

A fully working, responsive landing page for **Dekla AI** — an intelligent everyday assistant.

## Features

- Clean phone mockup (no decorative frames in front of the phone) with a live, animated chat demo
- Animated gradient background, scroll reveals and counting stats
- Responsive layout with a working mobile menu
- Monthly/yearly pricing toggle
- Accessible FAQ accordion
- Email capture forms with validation
- No build step — pure HTML, CSS and JavaScript

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Structure

```
index.html            # markup
assets/css/styles.css # styles
assets/js/app.js       # interactions (chat demo, forms, reveals, pricing toggle)
```
